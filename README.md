# projeto-1-maromo

NOME: Felipe Peraro Gomes e João Victor Januário

Neste trabalho foi desenvolvido um gestor hospitalar onde é possível adicionar a ficha médica de um paciente, contendo seu nome, idade, o nível de urgência que este paciente deve ser tratado e se ele possui plano de saúde ou não. Além disso, é possível também imprimir um relatório mostrando todos os pacientes que estão em estado urgente e crítico, a média da idade dos pacientes em estado crítico e quantos pacientes tem plano de saúde e fazer a busca do paciente mais idoso.

Enfrentei uma leve dificuldade de sintaxe ao programar os métodos usando stream, e para resolver isso, tive um leve auxílio de IA.
